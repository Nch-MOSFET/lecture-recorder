# 講義録音（LectureRecorder）

時間割どおりに授業を自動録音し、録音しながら端末内の音声認識で文字起こしする Android アプリです。
録音（`.m4a`）と文字起こし（`.txt`）を「科目名_日付」の名前で、科目ごとに決めた保存先へ書き出します。

すべて端末内で処理します。通信もアカウントも不要で、API 料金はかかりません。

## できること

- **時間割どおりの自動録音** — 科目ごとに曜日・時刻・授業日を登録すると、その時刻に録音を始めて終了時刻に止めます。開始前・終了後の余裕（0〜30分）も設定できます。
- **同時に文字起こし** — 録音中の音声を端末内の音声認識に渡し、`[時:分:秒] 本文` の形で書き出します。科目ごとに「日本語」「日本語＋英語（自動で切り替え）」「英語」を選べます。
- **保存先を科目ごとに指定** — Android のフォルダー選択で選びます（Google ドライブで動作確認済み）。未設定なら端末の `Documents/講義録音/{科目名}/`。書き出しに失敗したら端末内に残し、後で自動的に再送します。
- **授業日の指定** — 祝日や休講で授業のない週は録音しません。学期の最終回で自動的に終わります。
- **時間割ファイル（JSON）** — 時間割をまとめて読み込めます。書き方の説明が入ったサンプルと、今の時間割の書き出し（バックアップ用）もアプリから保存できます。
- **手動録音・次回のスキップ・中断した録音の回収**

## ダウンロード

ビルド済みの APK は [Releases](https://github.com/Nch-MOSFET/lecture-recorder/releases) からダウンロードできます。

1. 最新のリリースから `LectureRecorder-x.y.z.apk` をスマホでダウンロードします。
2. 開くと「提供元不明のアプリ」の許可を求められるので、ダウンロードに使ったアプリ（ブラウザなど）に許可してインストールします。
3. 更新するときも、新しい APK をそのまま開けば上書きインストールされます（設定は残ります）。授業中には更新しないでください。

APK は次の証明書で署名しています。インストール前に確かめたい場合は `apksigner verify --print-certs` で照合できます。

- 署名者：`CN=LectureRecorder`
- 証明書の SHA-256：`99:36:24:1f:2f:3a:d5:b8:e8:5a:63:e0:61:92:15:83:97:3f:15:f6:e9:46:eb:f4:cf:84:fc:3f:0e:72:6f:7f`

## 動作環境

- Android 12（API 31）以上。実機で確認したのは Pixel 7a（Android 17）です。
- 文字起こしには端末内の音声認識（Google の音声認識など）と、その言語モデルが必要です。入っていない端末では録音だけ行います。
- Android 12 では、録音中の音声を認識へ渡す仕組み（Android 13 以降の機能）が使えないため、認識エンジンが自分でマイクを使います。端末によっては文字起こしが無音になることがあります。

## 使い方

1. アプリを開き、「事前チェック」の項目（マイク・通知・電池の最適化の対象外・日本語の音声認識）をすべて通します。
2. 「＋ 授業を追加」で科目名・曜日・時刻・言語・保存先を登録します。まとめて入れるときは「JSON から時間割を読み込む」を使います。
3. 「時間割どおりに自動録音する」をオンにします。通知が出たまま待機し、授業の時刻に録音します。

> **注意**：Android の制限により、マイクを使う常駐サービスは画面が前面のときにしか開始できません。端末を再起動したときやアプリを更新したときは待機が止まるので、通知（「自動録音が止まっています」）をタップして再開してください。**授業中にアプリを更新すると録音が止まります。**

## 時間割ファイル（JSON）

```json
{
  "format": "lecture-recorder-timetable",
  "version": 1,
  "lectures": [
    { "name": "英語", "day": "水", "start": "10:40", "end": "12:10",
      "dates": ["2026-04-08", "2026-04-15"], "language": "ja+en" },
    { "name": "数学", "day": "月", "start": "9:00", "end": "10:30" }
  ]
}
```

- `name`・`day`・`start`・`end` が必須です。`day` は `月`〜`日`、`月曜`、`Mon`、1〜7 のいずれでも書けます。
- `dates` を省略すると毎週録音します。`language` は `ja`（既定）・`ja+en`・`en`。`enabled` に `false` を入れると自動録音しません。
- 書き方の説明は、アプリの「サンプルを保存」で出力される JSON の `_説明` に入っています（`_` で始まる項目は読み込み時に無視されます）。
- 読み込みは「追加・更新」（同じ科目名・曜日のコマだけ更新し、保存先は残す）と「置き換え」（ファイルにないコマを削除）から選べます。

PC から adb で取り込むこともできます。受信口は `android.permission.DUMP` で保護しているため、adb shell とシステム以外からは送れません。

```sh
adb shell am broadcast -n local.lecturerecorder/.ImportReceiver \
  -a local.lecturerecorder.IMPORT --es b64 "<JSON を Base64 にした文字列>"
adb shell am broadcast -n local.lecturerecorder/.ImportReceiver \
  -a local.lecturerecorder.DUMP   # 今の登録内容を表示
```

## ビルド

```sh
./gradlew assembleDebug        # テスト版
./gradlew testDebugUnitTest    # 単体テスト
./gradlew assembleRelease      # 配布版（署名の設定が必要）
```

JDK 21・Android SDK（platform 36）が必要です。外部ライブラリは使っていません（テストのみ JUnit と org.json）。
配布版を作る場合は、リポジトリ直下に `keystore.properties` を置きます（Git 管理外）。

```properties
storeFile=/path/to/your.keystore
storePassword=...
keyAlias=...
keyPassword=...
```

## 仕組み

- 録音は `MediaRecorder`（16kHz・モノラル・AAC 32kbps、90分で約20MB）。録音中は ADTS 形式で書き、停止後に m4a へ詰め替えます。途中で強制終了しても、そこまでの音声は残ります。
- 文字起こしは `SpeechRecognizer`（端末内認識）。Android 13 以降は録音と同じ音声をパイプ（`EXTRA_AUDIO_SOURCE`）で渡し、長時間用の分割セッションを使います。
- 授業の開始・終了は `AlarmManager` の正確なアラームで起こします。録音中は部分ウェイクロックを取り、画面が消えていても続けます。
- 電池の減りは、90分の録音＋文字起こしで約10%でした（Pixel 7a）。
